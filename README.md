# Skipify 🎧

### Skip the boring. Play the best.

Skipify is a Chrome extension that automatically jumps to the most engaging part of YouTube videos and plays it with context — then skips to the next video.

Turn YouTube into a **highlight-only experience**.

---

## 🚀 Features

- 🔥 Automatically detects the best part of a video
- ⏩ Skips directly to the highlight
- ⏱️ Plays **10–12 seconds before** for context
- 🎧 Minimum **60 seconds playback**
- ⏭️ Auto-skips to next video
- 🎛️ ON/OFF toggle for normal viewing
- 🧠 Works even without replay data

---

## 🧠 How It Works

Skipify uses:

- YouTube "Most Replayed" heatmap (when available)
- Smart fallback (60% of video duration)
- Context-aware playback logic

---

## 📦 Installation (Manual)

1. Download this repo as ZIP
2. Extract it
3. Open Chrome and go to:

```
chrome://extensions/
```

4. Enable **Developer Mode**
5. Click **Load Unpacked**
6. Select the project folder

---

## 🎮 How to Use

- Open any YouTube video

- Skipify will automatically:
  - Jump to the best part 🎯
  - Play it with context 🎧
  - Move to next video ⏭️

- Use toggle button to enable/disable anytime

---

## 🛠️ Tech Stack

- JavaScript (Vanilla)
- Chrome Extension (Manifest v3)
- DOM manipulation
- YouTube internal data parsing

---

## 💡 Why Skipify?

Because:

> Not every second of a video deserves your time.

Skipify removes the boring parts and delivers only what matters.
